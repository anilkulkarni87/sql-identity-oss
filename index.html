    ⚡ 60-Second Quickstart¶

    Run a complete synthetic multi-source identity resolution pipeline locally on DuckDB:

    # 1. Install with DuckDB, Web UI, and MCP extras
pip install "sql-identity-resolution[duckdb,ui,mcp]"

# 2. Run the 10,000-row synthetic quickstart demo
idr quickstart --rows 10000 --output demo.duckdb

# 3. Launch the interactive React Web UI & Cluster Explorer
idr ui --db demo.duckdb

    🏗️ Enterprise Capabilities Built In¶

    🔗 Deterministic + Fuzzy Graph Engine

    Anchor-based star edges (N-1 edges per group) prevent O(N²) clique explosion, paired with iterative Label Propagation and optional blocking-key fuzzy super-clustering.

    🧼 Domain Canonicalizers & Custom SQL

    Built-in normalizers (EMAIL_STANDARD, EMAIL_STRIP_PLUS, PHONE_DIGITS, PHONE_US_10, ALPHANUMERIC_UPPER) plus custom warehouse SQL templates via {val}.

    🛡️ Poison-Pill Exclusions & Guardrails

    Built-in blocklist (use_default_exclusions: true), wildcard ANY rules, warehouse-table exclusions, and max_group_size thresholds stop bad data from creating mega-clusters.

    📌 Persistent Resolved IDs & Crosswalk

    "Largest Cluster Wins" stabilization preserves existing resolved_id values across incremental runs and logs every cluster merge or split into idr_out.resolved_id_crosswalk.

    ⚖️ Manual Stewardship Overrides

    Override graph links with FORCE_LINK, DO_NOT_LINK, and ISOLATE via YAML, SQL (idr_meta.identity_override), Web UI Explorer, or dbt_idr seeds.

    🗑️ GDPR / CCPA Right-to-be-Forgotten

    Purge entities or identifier values across all output and staging tables with idr privacy forget while recording an immutable compliance receipt in idr_meta.privacy_audit_log.
